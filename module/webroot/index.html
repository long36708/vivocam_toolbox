本机型没有匹配的 profile，模块不会伪装机型、不会铺移植库，以免把相机弄坏。 你仍可以：备份原厂库、查看崩溃归因、切回原厂相机。

「切回原厂」依赖原厂属性快照（首次开机自动采集，或用上方按钮手动采集）。 快照记录的是本机真实机型码，不依赖任何预设型号。
自动采集机型身份/原厂相机路径/HAL 格式并生成 profile，生成后立即验证匹配； 导入插件即可试切。已有同名 profile 时会拒绝（防覆盖实测回填）。
手机重启后机型伪装属性会还原，移植相机会闪退——回来点一下这个即可恢复，无需重装。
点上方卡片切换相机版本，全程约 15 秒、无需重启。切换不清数据、设置保留；若切换后出现异常（崩溃循环/快门失灵），多为跨版本设置残留，用 root shell 执行 cam.sh clear。
